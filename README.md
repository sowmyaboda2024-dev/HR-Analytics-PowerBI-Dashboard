HR Analytics Dashboard - Power BI

Project Overview
This project analyses employee attrition patterns and workforce demographics using Power BI.
The dashboard helps HR teams identify key factors driving employee turnover and provides actionable insights to improve retention strategies.

Tools Used
	• Power BI Desktop 
	• Power Query 
	• DAX 
	• Data Modelling 
	• Data Visualization 

Dataset
Source:
IBM HR Analytics Employee Attrition Dataset (Kaggle)

Key Insights
	• Overall attrition rate is 16.12%. 
	• Employees working overtime show higher attrition. 
	• Sales department experiences significant turnover. 
	• Employees with lower salaries contribute the highest attrition. 
	• Business travel frequency impacts employee retention.
